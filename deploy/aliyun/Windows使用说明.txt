Forge 简体中文社区版 Windows 使用说明

1. 本软件完全免费。玩家交流与问题反馈请加入 QQ 群：813597628。
2. 请先将 ZIP 完整解压到普通目录，不要直接在压缩包中运行。
3. 双击 forge.exe 启动。
4. 程序已内置专用 Java 21 JRE，无需安装 JRE 或 JDK，也不会使用系统中的 Java。
5. 请勿删除或移动 runtime、res 目录以及主程序 JAR。
6. Windows SmartScreen 首次提示时，请核对文件来源和发布的 SHA-256 后再选择运行。
7. 更新前建议备份用户目录中的套牌、存档和配置。
