08.25 主要更新

1. 中央大厅与中继联机
- 新增由社区服务器提供的中央房间大厅，可直接查看、创建和加入房间。
- 桌面版与 Android 版可通过中央中继互相联机，不再要求房主拥有公网 IP、配置端口转发或手动分享 IP 地址。
- 大厅控制连接使用 TLS 加密；游戏数据由中继服务器透明转发。
- 保留房间名称、房主、赛制、人数上限和密码房间等信息。

2. Android 联机稳定性修复
- 修复 Android 创建大厅房间时卡在“正在创建”并最终出现 software caused connection abort 或 read timed out 的问题。
- 修复 Android 加入桌面端房间时长期停在“连接到服务器”、房主收不到加入提示的问题。
- 将中继控制帧读取改为可靠的完整读取方式，统一修复房间注册、加入确认、反向隧道和登录握手链路。
- 修复后台网络线程与界面线程之间的等待竞争，避免操作完成后界面仍无法继续。
- 已在真实 Android 14 设备上完成双向验证：Android 建房可由 PC 加入，PC 建房也可由 Android 加入。

3. Windows 内置精简 JRE
- Windows 完整版改为内置专用 Java 21 JRE，不再携带包含 javac、javadoc、jmods 等开发工具的完整 JDK。
- 用户仍然无需安装 Java，双击 forge.exe 即可启动。
- 程序只使用安装包内的 JRE，不受系统 Java 版本和环境变量影响。
- 精简运行环境可明显降低桌面压缩包体积和解压后的磁盘占用。

4. 延续的社区版特性
- 默认使用简体中文界面，并提供卡名、规则术语和界面文本汉化。
- Android 内置完整 CJK 字库；中文输入使用系统原生输入对话框，支持拼音组合、候选词选择和一次性提交。
- 客户端更新、Android 资源包和中文卡图均使用社区维护的下载服务。
- 卡图按需下载；桌面版与 Android 版均不提供“一次下载全部卡图”功能。
- 官方 Discord、论坛和错误上报入口已替换为 QQ 群 813597628，程序不会向原版 Sentry 服务自动提交错误报告。
- 包含截至 2026 年 8 月 24 日的 Card-Forge/forge 上游更新。

安装与升级提示

- Windows：下载 ZIP 后完整解压到普通目录，再双击 forge.exe；不要直接在压缩包内运行，也不要删除 runtime 或 res 目录。
- Android：下载 APK 后直接安装；签名一致时可以覆盖安装并保留用户数据。
- 首次安装 Android 后，程序可能继续下载约 181 MiB 的基础资源，请使用稳定网络并等待下载完成。
- 卡图按需从社区卡图服务器下载，首次查看尚未缓存的卡牌时需要联网。
- 更新前建议备份重要套牌、存档和配置。
