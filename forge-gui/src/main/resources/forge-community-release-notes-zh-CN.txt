Forge 简体中文社区版更新说明
版本：2.0.15-汉化-09.03
发布日期：2026年9月3日

重要说明

本版本是基于开源项目 Forge 制作的非官方民间汉化版本，与 Card Forge 官方及 Wizards of the Coast 无隶属或授权关系。

本软件、Windows 压缩包和 Android 安装包完全免费。请勿向任何人付费购买本软件，也请勿包装后进行收费销售。

问题反馈与交流请加入 QQ 群 813597628
民间汉化开源分支：https://github.com/kaorou-bot/forge/tree/zh-cn-community-release
Forge 原始开源项目：https://github.com/Card-Forge/forge

09.03 更新

1. 同步 Forge 上游与中文资料
- 合并截至2026年9月3日的 Forge 上游主干更新，并保留社区版中文、中央大厅和移动端修复。
- 随安装包更新简体中文卡牌翻译文件；翻译由构建发布流程同步，客户端不会在启动时额外下载。
- 缺少中文翻译的少量 Forge 特有牌仍会安全回退显示英文。

2. 更新社区卡图镜像
- 增量加入255张卡图：LTC 181张、MBC 51张、SLD 20张、SOI 3张。
- 服务器卡图总数更新为56,371张；已有图片未覆盖、未重新编码。
- 保持按需下载方式，不提供一次下载全部卡图的功能。

3. 发布与兼容性
- Windows 与 Android 安装包统一更新为 cn0903。
- Windows 包继续内置专用 Java 21 JRE，无需另行安装 Java。
- 保留 Android 中文输入、完整 CJK 字库和桌面/移动端中央大厅联机支持。

09.01 更新

1. 同步 Forge 上游更新
- 合并截至2026年9月1日的上游主干更新，包括AI判断、卡牌脚本、系列资料、冒险模式和移动端渲染改进。
- 修复AI评估费用时可能发生的空指针崩溃。
- 改进AI对法术力来源、牺牲费用、展示牌张、复制生物和战斗时机的判断。
- 更新部分系列资料、卡牌定义和新增的冒险模式中文文本。

2. 修复《风暴之眼乌金》-11异能
- 修复Android单机中，-11异能放逐无色非地牌后，点击放逐区牌张没有反应的问题。
- 修正复制或包装后的能力来源判断，确保“本回合可以免费施放”许可不会被同一次放逐事件立即清除。
- 已对《寇基雷的指命》和另一张《风暴之眼乌金》完成真实堆栈路径回归测试。

3. 稳定性与兼容性
- 合入上游移动端资源释放、覆盖文字渲染和界面生命周期改进。
- 保留中文输入对话框、完整CJK字库、社区更新与卡图镜像、中央大厅和中继联机功能。
- 桌面版和Android版继续共用相同规则引擎与社区服务配置。

08.25.2 更新

1. 支持 2–8 人房间
- 创建中央大厅房间时可以选择 2、3、4、5、6、7 或 8 人上限。
- 桌面版与 Android 版使用相同的人数设置和中继协议。
- 修复超过 2 人时房间配置与比赛启动可能崩溃的问题。
- 已完成真实 3 人、4 人和 8 人中继联机流程测试。

2. Android 赛后退出修复
- 修复 Android 玩家结束一局对战后无法离开房间的问题。
- 修复房主先结束比赛并回到房间后，客机右上角菜单没有反应的问题。
- 客机收到比赛结束通知时，会先清理胜负结算层和比赛临时界面，再返回房间，避免不可见界面继续拦截菜单操作。

3. 中央大厅与中继联机
- 社区服务器提供中央房间大厅，可直接查看、创建和加入房间。
- 桌面版和 Android 版可以通过中央中继互相联机，无需公网 IP、端口转发或手动分享 IP 地址。
- 大厅控制连接使用 TLS 加密；游戏数据由中继服务器透明转发。
- 支持房间名称、房主、赛制、人数上限和密码房间。

4. 中文社区版特性
- 默认使用简体中文界面，并提供持续维护的卡名与界面翻译。
- Android 内置 CJK 字库，并使用系统原生中文输入对话框支持拼音组合、候选词选择和一次性提交。
- 客户端更新、Android 资源包和卡图使用社区维护的下载服务。
- 卡图按需下载，不提供一次下载全部卡图的功能。
- Windows 包内置专用 Java 21 JRE，用户无需安装 Java。
- 问题反馈渠道为 QQ 群 813597628；程序不会向原版 Sentry 服务自动提交错误报告。

安装和更新提示

- Windows：将 ZIP 完整解压到普通目录后双击 forge.exe。不要直接在压缩包内运行，也不要删除 runtime 或 res 目录。
- Android：下载 APK 后直接安装；签名一致时可以覆盖安装并保留用户数据。
- 首次安装 Android 后，程序可能继续下载约 181 MiB 的基础资源，请使用稳定网络并等待下载完成。
- 更新前建议备份重要套牌、存档和配置。
