重要说明

本版本是基于开源项目 Forge 制作的非官方民间汉化版本，与 Card Forge 官方及 Wizards of the Coast 无隶属或授权关系。

本软件、Windows 安装包与压缩包、Android 安装包完全免费。请勿向任何人付费购买本软件，也请勿包装后进行收费销售。

问题反馈与交流请加入 QQ 群 813597628
民间汉化开源分支：https://github.com/kaorou-bot/forge/tree/zh-cn-community-release
Forge 原始开源项目：https://github.com/Card-Forge/forge

09.22.4 更新（桌面版修复）

1. 修复 FRA 现开与新卡加载
- 修复桌面正式版跳过 upcoming 目录中的新卡，造成 FRA 现开牌池异常、反复出现少量旧牌的问题。
- 统一目录资源与安卓压缩资源的新卡加载规则，正常加载随包提供的新系列卡牌；同时覆盖延迟加载路径。
- 已通过 FRA 普通牌全量检查、六包现开测试和桌面用户验收。
- 之前已经保存的异常现开牌池不会自动重抽，请更新后重新创建 FRA 现开。

2. 发布与兼容性
- 桌面版 cn0922r4 提供完整安装包、内置 JRE 的便携包，以及从 cn0922r3 升级的增量安装包。
- 安卓版保持 cn0922r3，资源包保持原版本；本次无需重新安装安卓或下载资源。
- 中文卡牌翻译已与独立翻译项目核对，内容未变；tokens 镜像与普通卡图下载保持不变。
- 不修改或重启联机大厅和中继服务，不影响在线用户。

09.16 更新

1. 支持中文套牌导入
- 桌面版和安卓版均可导入中文牌名，支持中英文混合列表、双面牌及单独牌面、备牌、系列与收藏编号。
- 支持中文标点和罕见汉字；使用英文界面时也可导入中文牌名。
- 使用随包的本地中文翻译，不需要额外联网。遇到同名歧义或缺少翻译时不会任意选择其他卡牌。

2. 简化首次启动
- 移除桌面版和安卓版首次启动时下载英文卡图索引的询问弹窗。
- 保留已有的离线启动修复及卡图按需下载功能。

3. Windows 安装包与后续增量更新
- Windows 提供完整 EXE 安装包，内置 Java 21 JRE，无需另外安装 Java。
- 首次使用安装包后，后续适用版本可只下载变化的文件；版本不匹配时使用完整安装包。
- 现有便携版用户本次需要安装完整包。旧版自动更新可能只打开下载目录，请手动运行下载的 EXE。
- 安装目录与套牌、存档、卡图缓存分开，安装器不会覆盖用户自定义的 forge.profile.properties。

4. 发布与兼容性
- Windows 与 Android 正式版更新为 cn0916，Android 保持原有签名并递增安装版本号。
- 已检查固定翻译分支，当前38,069条中文翻译与上一版相同。
- 本次不修改联机大厅和中继服务，不需要重启服务器。

08.25.2 更新

1. 支持 2–8 人房间
- 创建中央大厅房间时可以选择 2、3、4、5、6、7 或 8 人上限。
- 桌面版与 Android 版使用相同的人数设置和中继协议。
- 修复超过 2 人时房间配置与比赛启动可能崩溃的问题。
- 已完成真实 3 人、4 人和 8 人中继联机流程测试。

2. Android 赛后退出修复
- 修复 Android 玩家结束一局对战后无法离开房间的问题。
- 修复房主先结束比赛并回到房间后，客机右上角菜单没有反应的问题。
- 客机收到比赛结束通知时，会先清理胜负结算层和比赛临时界面，再返回房间，避免不可见界面继续拦截菜单操作。

3. 中央大厅与中继联机
- 社区服务器提供中央房间大厅，可直接查看、创建和加入房间。
- 桌面版和 Android 版可以通过中央中继互相联机，无需公网 IP、端口转发或手动分享 IP 地址。
- 大厅控制连接使用 TLS 加密；游戏数据由中继服务器透明转发。
- 支持房间名称、房主、赛制、人数上限和密码房间。

4. 中文社区版特性
- 默认使用简体中文界面，并提供持续维护的卡名与界面翻译。
- Android 内置 CJK 字库，并使用系统原生中文输入对话框支持拼音组合、候选词选择和一次性提交。
- 客户端更新、Android 资源包和卡图使用社区维护的下载服务。
- 卡图按需下载，不提供一次下载全部卡图的功能。
- Windows 包内置专用 Java 21 JRE，用户无需安装 Java。
- 问题反馈渠道为 QQ 群 813597628；程序不会向原版 Sentry 服务自动提交错误报告。

安装和更新提示

- Windows：将 ZIP 完整解压到普通目录后双击 forge.exe。不要直接在压缩包内运行，也不要删除 runtime 或 res 目录。
- Android：下载 APK 后直接安装；签名一致时可以覆盖安装并保留用户数据。
- 首次安装 Android 后，程序可能继续下载约 181 MiB 的基础资源，请使用稳定网络并等待下载完成。
- 更新前建议备份重要套牌、存档和配置。
