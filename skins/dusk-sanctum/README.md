# 暮辉秘境 · Dusk Sanctum

PC 双人对战皮肤。暗蓝石质桌面、古铜金边、中文字体、无框扇形手牌。

需要支持 match-ui v3 的 Forge 桌面主程序（本仓库 codex/desktop-match-ui 分支）。
旧版 Forge 不能直接使用此包；升级主程序一次后，修改本目录的 JSON、图片或字体即可更换皮肤，无需编译 Java。

## 导入

在对局中打开「布局 → 对战界面 → 导入对战皮肤包」，选择 dusk-sanctum.zip。
导入后立即启用。已导入的包可在同一菜单的「已安装的对战皮肤」中切换。
选择「经典」可恢复原界面。

ZIP 根目录必须直接包含 match-ui.json、images/、fonts/，不要额外套一层 dusk-sanctum/。
安装位置是 Forge 用户偏好目录下的 desktop-match-skins/；再次导入会生成独立副本。
修改已安装副本后，使用「重新加载对战界面」应用。

## 行为

- 自己的手牌保持正面显示，可点击出牌或拖入战场；对手手牌只显示许可信息。
- 双方法术力池总数为零时隐藏整条法术力池。牌面上的施放费用不受影响。
- 堆叠为空时完全隐藏；有咒语或异能时显示可拖动的悬浮面板，保留原堆叠操作。
- 面板避让手牌、响应按钮以及右侧卡图/卡牌详情；默认出现在详情左侧。
- 卡图、卡牌详情、日志等标签使用资源包的古铜色样式，选中标签高亮。
- 「对战操作」打开独立窗口，可拖动和调整大小；选择操作后收起，也可按 Escape 关闭。
- 战场、手牌不绘制原来的矩形边框；阶段、生命、牌库等独立定位。
- 此包为双人布局；多人或需要显示多个受控手牌时由主程序回退到可容纳全部玩家的布局。
- 悬浮窗口位置在当前对局中保留，不跨重启保存。

## 修改

match-ui.json 使用 0–1 相对坐标。appearance 指定资源与颜色，widgets 定位独立控件，
floating 指定悬浮文档，visibility 配置条件显示，cards 指定手牌和战场排列。
不支持脚本或可执行文件。接口说明见仓库 docs/DesktopMatchUI.zh-CN.md。

背景是为本皮肤生成的独立美术资源；卡牌和头像由 Forge 自身加载，并未打包进皮肤。
这是一套受奇幻卡牌竞技场视觉启发的原创主题，并非官方 MTG Arena 皮肤。
Noto Sans CJK SC 字体来自 Noto 项目，遵循 SIL Open Font License 1.1，许可全文见 fonts/OFL.txt。
美术生成记录和字体来源见 ASSETS.md。
