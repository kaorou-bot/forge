# 暮辉秘境 · Dusk Sanctum

PC 双人对战皮肤，也是桌面客户端的内置制作示例。暗蓝石质桌面、古铜金边、中文字体、无框扇形手牌。

本次优化版需要支持 match-ui v4 的 Forge 桌面主程序。旧的 cn0930 正式安装包仅支持 v1～v3，须升级至附带此示例的新版测试客户端；产品版号和皮肤格式版本不是同一概念。
旧版 Forge 不能直接使用此包；升级主程序一次后，修改本目录的 JSON、图片或字体即可更换皮肤，无需编译 Java。

## 直接使用或导入

新版桌面客户端：对局中打开「布局 → 对战界面 → 暮辉秘境（内置示例）」，无需下载或导入。
菜单不再提供旧的「竞技场布局（示范）」和「桌面对战场景（预览）」。升级时旧选择会安全恢复经典布局。
内置资源封装在桌面 JAR 中，只读加载，不在首次使用时向用户目录释放文件。
Android 不受影响。既有用户导入的皮肤副本不会被覆盖，也不会随内置示例自动更新。

在对局中打开「布局 → 对战界面 → 导入对战皮肤包」，选择 dusk-sanctum.zip。
导入后立即启用，并永久保存。已导入的包可在同一菜单的「已保存的对战皮肤」中切换，退出重启后仍在列表中；当前副本会被标记选中。
选择「经典」可恢复原界面。

ZIP 根目录必须直接包含 match-ui.json、images/、fonts/，不要额外套一层 dusk-sanctum/。
安装位置是 Forge 用户偏好目录下的 desktop-match-skins/；再次导入会生成独立副本。
不需要的副本可在「删除已保存的皮肤…」中逐一选择并确认删除以释放空间；正在使用时先恢复经典布局，不结束对局。删除只影响选中的安装副本，不删除原 ZIP、其他皮肤或套牌；内置示例不在删除列表中。删除无法撤销，但可重新导入 ZIP；直接修改过安装副本时请先自行备份。
修改已安装副本后，使用「重新加载对战界面」应用。

## 行为

- 自己的手牌保持正面显示，可点击出牌或拖入战场；对手手牌只显示许可信息。
- 生物优先在战场中间排列；土地和其他永久物另起行。缩小手牌扇形角度与抬升，避免遮住响应按钮。
- 加宽双方名称和生命区域；牌库、坟墓场、放逐区采用图标与文字数量横向排列。
- 六边形头像轮廓和古铜边框；确认/取消按钮区分悬停、按下和禁用状态。
- 阶段采用一排上下分区按钮：上半为 FIELD_1（常规对局的对手），下半为 FIELD_0（自己），旁边标明归属；观战等无唯一本地玩家时显示“上方/下方”。悬停显示玩家名、阶段全称和操作说明。
- 左键只切换所点半区的停留设置，圆点表示停留开启；右键保留原让过目标功能，金色箭头表示目标。当前回合的当前阶段高亮对应半区，并显示左侧金色短线；不跟随优先权换行。切换回经典布局时双方设置保持不变。
- 卡牌详情改为右侧可拖动浮窗，与卡图分开；信息窗底板全透明，正文采用高对比浅白色，文字不透明。
- 日志、战斗、关联牌正文和内层滚动容器全透明；新增日志、切换标签后也不恢复白底。卡图、缩略图、按钮和生命/区域标识正常绘制。
- 双方法术力池总数为零时隐藏整条法术力池。牌面上的施放费用不受影响。
- 堆叠为空时完全隐藏；有咒语或异能时显示可拖动的悬浮面板，保留原堆叠操作。
- 面板避让手牌、响应按钮以及右侧卡图/卡牌详情；默认出现在详情左侧。
- 卡图、卡牌详情、日志等标签使用资源包的古铜色样式，选中标签高亮。
- 「对战操作」打开独立窗口，可拖动和调整大小；选择操作后收起，也可按 Escape 关闭。
- 战场、手牌不绘制原来的矩形边框；阶段、生命、牌库等独立定位。
- 此包为双人布局；多人或需要显示多个受控手牌时由主程序回退到可容纳全部玩家的布局。
- 悬浮窗口位置在当前对局中保留，不跨重启保存。

## 修改

本示例使用新版 v4 的 `cards.battlefield:"adaptive"`：生物仍居中，地与非生物非地永久物在后排左右并列，各自换行、不越左右中线；超宽牌叠等比缩小，牌多时纵向滚动。需要资料包 1.1.5 对应或更新的客户端。旧导入副本不会自动覆盖，请升级客户端后导入新 ZIP，或在原稿中修改此字段再导入。需要旧 v4 客户端兼容时保留 `lanes`。

match-ui.json 使用 0–1 相对坐标。appearance 指定资源与颜色，widgets 定位独立控件，
floating 指定悬浮文档，visibility 配置条件显示，cards 指定手牌和战场排列。
不支持脚本或可执行文件。基础布局规范见 docs/DesktopMatchSkin-AI-Spec.zh-CN.md，新增字段见 docs/DesktopMatchSkin-v4.zh-CN.md。
复制本目录后修改 id 再制作自己的版本；不要试图直接修改已打包程序内的资源。离线制作资料包包含同一份原件和可导入 ZIP。

背景是为本皮肤生成的独立美术资源；卡牌和头像由 Forge 自身加载，并未打包进皮肤。
这是一套受奇幻卡牌竞技场视觉启发的原创主题，并非官方 MTG Arena 皮肤。
Noto Sans CJK SC 字体来自 Noto 项目，遵循 SIL Open Font License 1.1，许可全文见 fonts/OFL.txt。
美术生成记录和字体来源见 ASSETS.md。
