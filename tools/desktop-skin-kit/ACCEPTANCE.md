# 皮肤交付验收清单

## 制作环境内可完成

- [ ] 独立 id、明确适用接口版本和人数。
- [ ] 字体、背景、许可均在皮肤目录内，路径用 `/`。
- [ ] validate 通过，保存原始报告与 warnings。
- [ ] 检查容量矩阵，区分 scene 与 arena_fallback。
- [ ] 查看离线示意图，关键区域足够大，浮层有空位。
- [ ] pack 后再次 validate ZIP，确认根部直接有 match-ui.json。
- [ ] README 记录适用窗口、缩放、安装方法及未验收项。
- [ ] 保留图片来源与字体许可，不含私人文件和可执行代码。

## 必须用兼容 Forge 桌面程序完成

- [ ] 导入并启用后无错误，无意外回退。
- [ ] 中文字形齐全，长提示、名字和按钮文字不截断。
- [ ] 调度、抽牌、弃牌、点击出牌、拖牌出地正常。
- [ ] 费用支付、选目标、确认、取消正常。
- [ ] 非空堆叠可查看，清空后按设计隐藏。
- [ ] 法术力条、生命、玩家指示物和阶段及时更新。
- [ ] 各区域、预览详情、日志与完整对战操作可达。
- [ ] 复杂战斗、附件、牌叠和目标连线正确。
- [ ] 浮层拖动无明显遮挡和背景残影。
- [ ] 小窗口、最大化、实际高 DPI 缩放下可操作。
- [ ] 观战、多人、受控手牌变化下信息不泄露或丢失。
- [ ] 经典布局往返、对局结束再开时无残留。

记录：主程序版本/构建、测试日期、操作系统、窗口大小、缩放比例、测试人员、未通过项。

只做过静态检查时写“已静态校验，待实机验收”，不要写“全部适配、所有功能测试通过”。
