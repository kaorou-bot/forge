# 赛事套牌与统计接入

本功能复用 cardlist 的只读服务，不在 Forge 客户端抓取赛事网站，不修改联机大厅服务。开发基线为 cn1020；本轮不修复此前单独记录的 Android 12 Quest 兼容性问题。

## 用户入口

- 桌面：Forge 菜单 → 赛事套牌。
- 安卓：最外层主页菜单 → 套牌管理下方的“赛事套牌”，不在“新游戏”内部；保留旧导航索引，只调整按钮显示顺序。
- UI 使用 Forge 自带的皮肤、列表、下拉框、按钮及输入对话框，不嵌入网页。
- 默认标准赛制；可选择服务端提供的其他赛制。
- 浏览流程为赛事列表 → 赛事套牌列表 → 原生只读 `FDeckViewer`。不再生成中间详情／导入页面。关闭查看器直接返回赛事套牌列表，保持该列表及滚动位置。
- 根列表对服务端分页返回的牌表按 `format_code + event_id` 聚合，“加载更多赛事”跨页去重，不用相同赛事名合并不同比赛；搜索可按套牌／牌手／赛事关键词筛出相关赛事。
- 进入赛事时参考 cardlist `ServerEventDeckLoader`，按赛制、名称、日期逐页查询，再严格过滤赛事 ID；展示服务端收录的完整赛事牌表，而非仅首次分页命中的几副。结果不足服务端赛事牌数时提示刷新，不静默展示半份列表。
- 查看器复用套牌编辑器的 CardManager，支持卡图／列表、主备牌／指挥官分区和单卡详情；增加右上角菜单“保存到我的套牌…”，仍先弹改名确认再保存。其他场景的查看器不带此操作，也不开放牌表编辑权限。
- 本地不支持某些卡牌时，弹出缺失原因，不生成删减版或替代牌预览；导入仍被阻止。
- 套牌封面使用服务端 `representative_card.name`，不自行选第一张牌。参考 cardlist 插画封面与居中填充方式，移动端复用 Forge 的 `getCardArt`（适配牌面类型），桌面端裁取全卡上部插画；图片沿用 Forge 缓存与下载机制，不新增 Scryfall 查询或服务端改动。无代表牌或本地不支持时显示占位。
- 统计提供 7 天、30 天主牌／备牌使用率，显示快照日期、统计窗口、样本数、百分点变化和同步未完成提示。数据是 MTGTop8 收录样本，不是全部赛事，更不是对局胜率。
- 使用率保留服务端英文牌名作为匹配键，不从格式化中文标题反解析。每行显示 Forge 原生缩略卡图；安卓长按打开 CardZoom，桌面长按或双击打开原生只读单卡查看器（含规则与翻面）。本地未收录的牌显示占位符及统计文字；缺图沿用 Forge 卡图缓存／下载策略，不阻塞统计接口。

## 导入与保存

1. 获取完整牌表并核对服务端声明的数量，不使用摘要拼造牌表。
2. 通过 Forge 本地卡牌库匹配英文正式名称；兼容双面全名、斜线格式、重音与弯引号。归一化后不唯一的牌名不得模糊替换。
3. Forge 无法识别的牌会列出并阻止保存，不丢牌、不替换成其他牌。
4. 弹出名称输入框，用户可修改默认名称或取消。
5. 普通构筑存入 `ForgeConstants.DECK_CONSTRUCTED_DIR`；EDH/cEDH 存入 `ForgeConstants.DECK_COMMANDER_DIR`。实际绝对路径由用户的 Forge 配置决定，成功后在页面显示。
6. 使用标准 `.dck` 格式，写入来源 URL、赛事、日期、牌手和成绩备注。主牌、备牌、指挥官分区分别保存。
7. 服务端 `commanders` 是 `mainboard` 的子集，导入必须扣除主牌中的对应数量，再写入 Commander 分区，不能重复加入。
8. 同名（含大小写冲突）或已有磁盘文件不覆盖。保存后读回核对；失败仅回收本操作创建的目标，不动既有套牌。

本地保存不依赖服务器，之后离线仍可使用已导入套牌。浏览刷新失败保留当前已显示结果；换筛选条件时清掉旧列表，避免把旧赛制数据标为新赛制。

## 服务与代码边界

基础地址：`https://play.mtg-forge-kaorou.vip:8443/api/v1/`

- `GET decks/formats`
- `GET decks?format=...&page=...&page_size=30&q=...`
- `GET decks/{id}`
- `GET decks/card-usage?format=...&window_days=7|30&board=mainboard|sideboard`

`forge-gui/.../deck/tournament/` 为两端共享的模型、网络、展示状态和导入器。Swing 和 libGDX 分别由 `TournamentDialog` 与 `TournamentScreen` 展示。

网络请求不在 UI 线程执行；连接／读取都有超时，限制响应大小，不跟随重定向。关闭浏览器后旧请求结果不会回写界面。保存通过 Forge 原有集合 API 完成，使套牌选择器重新激活时能读取新增套牌。

移动端通过侧栏切换页面不会触发 `onClose`，因此自动套牌预览检查 `Forge.getCurrentScreen() == this`。页面已切走时不能抢占新页面；用户返回后可重新点击牌表。保存提示只允许当前赛事页或其查看器显示。

赛事牌表内系统／标题返回与底部返回都回赛事列表；加载中返回会取消当前任务并使迟到结果失效，实际应用销毁（空 callback）仍关闭线程。保存前检查本次请求代号，取消后不能继续写盘。滚动恢复使用显式 RESET / APPEND / RETURN_TO_EVENTS 状态，重复赛事页追加仍保留位置，切换筛选或统计不恢复旧赛事滚动位置。

`TournamentBrowser` 登记活动控制器实例，普通关闭后移除；`Forge.dispose` 在关闭当前页面前调用赛事专用 `closeAll()`，确保当前页是查看器、统计页或其他页面时，后台赛事请求也会失效且工作线程关闭。该清理不改变其他模式的页面 `onClose` 契约。

## Android 方向一致性修复

用户反馈关闭横屏重启后，系统仍横屏但 Forge 按竖屏堆叠布局。`Main.loadGame` 现在在 libGDX 初始化之前对横屏和竖屏对称设置 `SCREEN_ORIENTATION_SENSOR_*`，不依赖正常开场动画分支，覆盖低内存警告及 `run_anyway` 路径。移除把 Configuration.orientation 数值误当 ActivityInfo 常量的调用。`Forge.resize` 同步更新屏幕尺寸与相机，避免系统异步旋转后新页面仍使用开场旧尺寸。本轮仅编译与静态审查，不声称设备切换已实测。

安卓 APK 沿用 `assets/localization` 内置语言资源。启动时须在 Localizer 第一次读取外部语言目录前安装这些文件，使使用旧资源包的安装也能显示新中文入口；本轮仅接入语言安装，不调整字体、纹理或冒险模式启动逻辑。
