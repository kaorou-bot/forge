# cn0929net1 联机测试验收

这是测试包，未切换正式客户端更新渠道。若程序提示安装线上正式版更新，验收期间选择跳过，避免覆盖回 cn0929。APK 的 versionCode 为 2026092902，沿用既有签名，可覆盖安装；不要为降级而卸载清空数据。

## 默认服务器

1. 两端安装本次测试包，进入联机页面。首次应默认“服务器连接（大厅中继）”，地址 `tls://play.mtg-forge-kaorou.vip:443`。
2. 安卓建房，PC 加入；再交换房主。测试 2 人，条件允许再测 3–8 人。
3. 完成一局后，房主先返回房间，安卓客机仍应能打开菜单并退出；再测试客机先退出和房主关闭房间。

## 直连

1. 两端选“直连（IP / 局域网）”，连到同一 Wi-Fi。房主创建房间，允许本地防火墙入站；同网测试时 UPnP 可选不启用。
2. 在房主菜单“服务器地址”查看局域网 IP；客机点加入并输入如 `192.168.1.50:36743`，不能使用 localhost/127.0.0.1。
3. 交换安卓与 PC 的房主，验证选套牌、准备、开局、结束、退房及再次建房。没有网络隔离的局域网无需社区大厅。
4. 公网直连需路由器端口映射及可入站的公网地址；失败不一定是客户端问题。不要关闭整个防火墙。

## 自建服务器与持久化

1. 按服务端包 README 部署到自己的机器，配置域名证书与 TLS 转发；不能把手机连到服务器的 127.0.0.1。
2. 两端选服务器模式，点击地址输入 `tls://自己的域名:443`，创建和加入同一房间。
3. 切回社区服务器时不应看到自建服务器的房间。测试取消输入、无效地址、留空恢复默认。
4. 切换直连后再切回服务器，自建地址应保留；完全退出程序重开后仍记住所选方式和地址。
5. 安卓横屏/竖屏均应可点击模式、地址、创建、加入；房间内不能更换正在使用的连接方式。

服务端的“服务器连接”是大厅中继，不是常驻游戏 AI 主机；房主仍需在线。客户端和服务器实机验收尚需以上步骤，自动化测试不能替代它们。
