# 游戏内动态堆叠描述汉化（2026-09-29）

## 问题与路径

实际反馈：黑暗祭礼的牌名已显示中文，但堆叠内容仍为
`Jacinta adds {B}{B}{B}.`。

这不是独立项目生成的 `cardnames-zh-CN.txt` 缺译。
该文件提供牌面固定规则译文；玩家名字、目标列表和即时数量由
`forge-game/.../ability/effects/*Effect.java#getStackDescription` 生成。
固定 Oracle 的近似匹配不能可靠翻译这些拼接结果，也不应该用固定牌面文字覆盖实时数量。

本次在描述生成处使用中英文资源模板，经
`SpellAbilityEffect.getStackDescriptionWithSubs`、
`SpellAbilityStackInstance`、`StackItemView` 传给桌面与安卓。
没有更改结算方法、卡牌脚本、网络协议、独立卡牌翻译来源或更新渠道。
联机仍沿用现有的主机生成描述、传送给客户端的机制；没有新增按客户端语言重新翻译的协议。

## 第一轮覆盖（2026-09-29）

- 产生法术力（含未确定具体颜色／数量时的“法术力”占位描述）。
- 抓牌，普通／随机弃牌及弃掉所有手牌，磨牌及可选磨牌。
- 获得／失去生命，包含“等同于以此法失去的生命”。
- 占卜、刺探、横置、重置、消灭与不能重生提示。
- 反击咒语／异能，除非支付费用及摧毁异能来源的附加描述。
- 伤害数值、目标、平均分配／自行分配及逐个目标的分配数值。
- 目标附注和多目标列表连接词。

示例结果：`Jacinta 加 {B}{B}{B}。`

## 第一轮保真原则与未覆盖范围

- 玩家名字、牌名及卡牌编号、法术力符号作为参数传入，不做全局英文单词替换。
- 原有牌面中文仍由 CardTranslation 提供；不手工修改生成的卡名文件。
- 两种语言的模板同步维护，英文单复数分别保留。
  `lblStackCards` 特意传入英文数词和数字两个参数：英文用数词，中文用数字；
  这是展示规则，不涉及游戏数量的修改。
- 复杂脚本自行提供的 `IfDesc`、`AmountDesc`、`NumCardsDesc`、
  特殊弃牌限制、辉耀条件、法术力用途限制等仍沿用原来的牌面匹配或英文回退。
  其他尚未模板化的效果也可能仍有英文；本次不是对所有卡牌所有分支的完整汉化。
  后续应继续在对应效果的生成位置补模板和测试，不能盲目替换最终文本。
- 不更改根据字符串辨认的内部选项、规则标识、快捷让过键或联机消息字段。

`adds`／单引号／中文／法术力符号、多玩家、数值和反击条件。
与 `CardTranslationTest` 同跑，避免破坏原有牌面译文。

从工作区根目录执行 Maven：

```powershell

mvn -pl forge-gui-android -am -DskipTests -Dcheckstyle.skip=true compile
java deploy/VerifyCjkFontCoverage.java
```

本次未提升版号、提交、推送、制作安装包或更新线上服务器。
发布时须按现有打包流程同时包含修改后的引擎和两份语言资源，不能只替换卡名文件。

## 第二轮补充（2026-09-30）

继续使用相同工作区，保留第一轮未提交的修改；未发布。

新增覆盖：

- 强化的力量／防御力变化、常见关键字、额外阻挡数量、直到回合结束、
  来源持续横置期间有效，以及下次重置步骤不能重置。
- 牺牲自己、所结附的永久物或指定数量／类别，可选牺牲；重置至多指定数量。
- 公开区域移区：回手、放逐（含牌面朝下）、坟墓场移回战场、横置／攻击状态进场、
  由你操控、洗入牌库、牌库顶／底及第 N 张位置、置入坟墓场、加入赌注。
- 辉耀的共通颜色条件，标准的本回合死去改为放逐条件。
- 五条明确匹配的法术力用途限制，包含生物、神器、无色、瞬间／法术及不能支付一般费用。
- 完整匹配的简单单色生物衍生物描述，保留实际数量、P/T、颜色、类别和已知关键字。
- 桌面及安卓堆叠视图的可选触发前缀。

`StackDescriptionTerms` 只接受完整的已知类型／关键字，不用于牌名或玩家名字。
未知关键字保留原样及大小写，避免把规则中的 `{U}` 改成 `{u}`。
不认识的衍生物类型／能力、动态衍生物覆盖参数，以及尚未确定的 X 数量，
保留完整原描述；不创建真实衍生物或消耗游戏对象编号来生成显示文字。

仍未覆盖的重点包括隐藏区域检索、复杂衍生物、其他特殊脚本条件、
非标准法术力用途限制等；第一轮“未覆盖范围”中已在本节列出的项目以本节为准。
不能据此宣称所有卡牌动态描述已经完全汉化。

- 字库审计仍为 3,927 个码点、0 缺字。
