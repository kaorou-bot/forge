日期：2026-10-23  
基线：2a192a9b660df9a4c8d7e9dd5cfeee8863f9544a，加上本地已验证但尚未提交的 Replay 汉化。

## 1. 用户确认的范围

同时处理：

- Quest Mode / 冒险之旅：决斗、挑战、卡牌商店、珍宝集市、宠物、奖励、轮抽锦标赛、指挥官子模式。
- Adventure Mode / 冒险模式：地图探索、角色与 NPC、任务对话、商店、竞技场、物品和规则说明。

不把“手机竖屏”等同于某一个内部模块。入口分别映射至 NewQuestScreen 和 AdventureScreen，后者会调用 switchToAdventure。两种模式需分别覆盖。安卓竖屏是文案长度与排版的主要设计目标；本轮默认不开展模拟器或实机测试。

## 3. 已确认的错误类型

### 意义相反或规则误导

- Penalty for Loss 现译“失败补偿”：应说明扣除或惩罚，不是补偿。
- Exclude Promos 现译“排除闪卡”：代码过滤 EDITION_NON_PROMO，指赠卡系列，与闪卡无关。
- Bonus Multiplier per Win 现译“每赢一次奖金加倍”：QuestWinLoseController 实际按配置值乘以已计入的胜场，再加到基础奖励，不是每次翻倍。
- Max Wins for Multiplier 的说明现译“获得这么多胜利后奖励会停止”：停止的是该项加成的增长，不是取消胜利奖励。
- Playset Size: Any Number 的说明现译“售卖卡牌时不保留”：原意是为套牌中数量不限的牌设置保留张数。
- Draft/Sealed 在 Adventure 奖品说明中分别出现“选秀/密封赛”，应统一为“轮抽/现开赛”。

### 术语和语体混杂

- Quest 被交替译为“冒险”“探索”“任务”；界面模式应称“冒险之旅”，NPC quest 才称“任务”。
- 同一段落混用“你/您”“套牌/牌组/卡组”“系列/版本”。
- Common/Uncommon/Rare 有“铁牌/银牌/金牌”等口语；规则、设置与帮助采用“普通/非普通/稀有”，不依赖图标颜色。
- Shandalar 入口旧译“山达尔”；现有独立中文卡表和官方中文均可核对为“山德拉”。

### 未接入翻译的资源

- QuestStallDefinition 的显示名与描述直接返回 XML 英文。
- QuestItemBasic 的购买名称、说明直接返回 XML 英文；部分子类另用 printf 组装数值。
- QuestPetController 的属性说明还拼接 Current stats / Upgraded stats 等英文。
- QuestDuelReader / QuestChallengeReader 从 .dck 中读取 Title、Description；部分标题又被设置为内部 name。
- MapDialog 支持 loctext/locname，但没有键时仍显示原文。
- Config 支持 languages/<文件名>-<语言>.json 等非 UI 资源覆盖。现有实现按基础文件名寻找覆盖文件，设计新覆盖文件时要检查同名文件碰撞。
- UIActor 的 tr(...)、MapDialog 的格式标签、动态任务 token 是不同的机制，不能用同一种大括号替换规则处理。

## 4. 术语与风格规范（候选）

| 原文/概念 | 建议中文 | 说明 |
| --- | --- | --- |
| Quest Mode | 冒险之旅 | 保留现有模式名 |
| Adventure Mode | 冒险模式 | 指地图探索模式 |
| quest（NPC 委托） | 任务 | 不替换 quest ID/变量 |
| duel / match / game | 决斗 / 比赛 / 单局 | 具体提示可以“对局”统称，但规则处区分比赛与单局 |
| best of 1 / 3 / 5 | 单局决胜 / 三局两胜 / 五局三胜 | 避免“匹配-BO” |
| Draft / Sealed | 轮抽 / 现开 | 不译成选秀、密封 |
| Common / Uncommon / Rare / Mythic Rare | 普通 / 非普通 / 稀有 / 秘稀 | 按万智牌中文术语 |
| Promo | 赠卡 | 系列筛选时用“赠卡系列”，不等于闪卡 |
| Foil | 闪卡 | 与赠卡、稀有度分开 |
| Credits | 积分 | Forge 自定义货币，保留 Quest 现有名，不与地图模式金币混同 |
| Gold | 金币 | 地图模式货币 |
| Mana Shards | 法术力碎片（候选） | Forge 自定义资源；长文用全称，紧凑标签可用“碎片”。不是声称存在官方道具名 |
| Pet / Bazaar / Spell Shop | 宠物 / 珍宝集市 / 卡牌商店 | 保留现有玩家熟悉的用语 |
| Shandalar | 山德拉 | 以官方资料及现有中文卡名核对 |
| 卡牌、人名、时空名 | 优先既有中文专名 | 可查独立卡表但不修改它；无法确认的名字保留英文并列待核表 |

规则提示：简洁、明确、忠实，条件与结果先后清楚，不加入原文没有的机制。  
系统称呼：统一用“你”，无需称呼时省略。  
NPC 对话：自然的奇幻冒险语气，保留人物性格和幽默，不使用生硬公文腔、不随意网络化或添加剧情。  
界面标签：短句；完整解释放在说明，不用缩写牺牲规则准确性。

## 6. 样例评审：剧情与道具

### Quest 挑战：披着羊皮的狼

来源：quest/challenges/A Wolf in Sheep's Clothing.dck。当前标题和说明是英文。

原文说明：

> The local sheep farm is under attack by a pack of wolves. Kill the wolves, save the sheep!

候选标题：披着羊皮的狼  
候选说明：一群恶狼袭击了当地的牧羊场。击退狼群，救下羊群！

只翻译显示层。该文件中的 quest8、数字 ID、卡牌英文名、衍生物参数及奖励字段全部保持不变。

### Quest 集市：灵巧手法，第一卷（候选道具译名）

来源：bazaar/index.xml，Sleight / Sleight of Hand Vol. I。

原文要点：书中讲解高难度手法；效果为首次调度免费。  
候选：

> 这本书讲解了种种高明的手法，助你从容应对不理想的起手。  
> 效果：首次调度不减少起手牌张数。

这是 Forge 道具名称，不冒称万智牌官方牌名。落地前核对免费调度与各子模式的叠加行为，必要时保留“首次调度免费”并另加提示。

### Adventure 山德拉任务：悬赏搭档（Go Forth and Slay，候选任务标题）

原文目标：

> Defeat two $(enemy_1)s and collect a reward.

候选目标：

> 击败两名“$(enemy_1)”，然后领取报酬。

其中 $(enemy_1) 必须原样保留，并在抽样时检查非人形敌人的量词；如“名”不适用，改为“击败‘$(enemy_1)’两次，然后领取报酬”，同时核对这两种表述是否符合任务计数机制。

原文开场含义：一个憔悴的老人突然从街边招呼玩家，自称知道悬赏发布者。

候选开场：

> “喂，说你呢！就是那个一脸惊讶、看起来很厉害的法师。”街边一个憔悴的老人冲你喊道。可你明明记得，几秒前那里还空无一人。

候选选项：

> “厉害的法师这点倒没说错。找我什么事？”

原文提议含义：老人无力战斗又缺钱，让玩家击败两个指定敌人，双方分享报酬。

候选对话：

> “没什么陷阱，就是做笔交易。我现在动不了手，手头又紧。你去收拾两个‘$(enemy_1)’，一个算你的，一个算我的。我带你见发悬赏的人，报酬咱们分。”

候选接受/拒绝选项：

- “成交。”（接受任务）
- “这趟买卖不值得。”（拒绝任务）

此处只审阅语体；正式翻译必须逐分支保留原文具体信息，不能将不同分支统一成两句模板。

### NPC 拒绝后提示

原文：Come back tomorrow and perhaps I'll have something that you'll actually be willing to do.

候选：明天再来吧。说不定到时会有份你愿意接的差事。

## 7. 落地时的技术边界

- 不修改 cardnames-zh-CN.txt；按独立项目更新流程使用。
- 不修改任务 ID、flag、条件、奖励数值、敌人选择器、套牌牌表、资源路径、保存键。
- Quest 标题部分参与内部名称：保留原始 title/name，另取显示译文；不得直接改 .dck 的 Name 或被用作 ID 的 Title。
- 自定义资源未有译文时回退原文，不报错，不拿近似字符串错误匹配。
- 地图对话本地化优先利用已有 loctext/locname 和语言资源机制。任何新增映射须绑定稳定上下文，避免不同人物的相同英文句子被错误统一。
- 保留 {0} 等 MessageFormat 参数、%d/%.2f%% 等 printf 格式、项目自定义 %n、$(enemy_1)/$(poi_2) 等任务 token、{var=player_name} 及颜色/动画标签。
- 大括号在 MessageFormat 与文本动画中用途不同，必须按实际调用链转义；不要机械地把所有大括号视为参数。
- 检查 MapDialog 等使用原文比较来决定行为的旧实现；需先判定行为再格式化显示，不能让译文改变开门/返回等动作。
- 修改共享语言键会影响桌面端，这是共享资源的正常结果；检查桌面标签是否仍适用。
- 新增中文字符需纳入字库扫描；JSON/TMX/XML 的中文资源也需要纳入，而不仅扫描主语言表。
- Android APK 中的少量内嵌本地化资源不等同于完整 res。后续发布必须核对资源包内 adventure/quest 与语言表版本；当前盘点不声称已验证所有打包路径。

## 8. 批次与验收

1. 用户确认本文的术语和对话风格；无需逐句确认后续常规翻译。
2. 两种模式的共享界面、设置、结算和动态提示：先修会误导玩法的文案。
3. Quest 集市/宠物/主挑战，Adventure 默认世界/common 任务和 NPC 对话：补齐显示层的本地化入口。
4. 扩展世界、套牌描述：按目录逐批审校，单独标记生成文本、玩家自定义内容和待考证专名。
5. 独立测试：字面键/重复键/占位符/标签/UTF-8；对照非显示字段；语言切换、旧存档与原文回退；桌面与移动模块编译；必要的资源路径测试和字体覆盖。
6. 测试报告必须区分源码/资源检查、自动化验证与未覆盖的真实 UI。默认不使用实机或模拟器。
7. 用户明确授权后才更新版号、打包、提交、推送和部署。

此前 Replay 的 43 项测试只覆盖此前改动，不是本轮冒险润色验收。
