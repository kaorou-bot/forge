## 同步入口与并发保护

从主工作区执行（PowerShell 7）：

```powershell
$session = & ./deploy/prepare-upstream-workspace.ps1 -Mode Prepare | ConvertFrom-Json
# 在 $session.workspace 内完成同步、测试和推送。
& ./deploy/prepare-upstream-workspace.ps1 -Mode Finish -RunId $session.runId -Result success
```

没有变化时 Finish 使用 `unchanged`，本次失败时使用 `failed`。脚本通过 Git 公共目录内的锁文件和任务租约防止重入；存在未结束租约、脏工作树、未完成 Git 操作或未发布提交时拒绝继续，不会重置或清理工作树。只能快进到已获取的发布分支。

用 `-Mode Inspect` 查看状态。任务被强制终止时，先检查任务及对应工作树，确认本次任务确实结束、保存未提交/未发布工作后，才用记录的 runId 执行 Finish；不要自行过期、删除其他任务的租约。默认 Prepare 会获取发布分支及译表分支，`-SkipFetch` 仅供离线脚本测试，不用于正式同步。

## 发布物集中留存

### 失败合并的受控恢复

确认上次任务已停止、失败租约属于固定同步树后，检查实际 HEAD、MERGE_HEAD 和未提交文件。调用主工作区脚本的 `-Mode Prepare -ResumeCommit <完整HEAD> -ResumeMergeHead <完整单一MERGE_HEAD> -FailedRunId <失败runId>`，重新获取新租约；继续工作后用新 runId Finish。脚本不重置文件/索引，不执行 abort，不接受多目标合并、rebase/cherry-pick 或他人的活动租约；原失败租约在 Git 公共目录的 `forge-upstream-sync-history` 留档。不得手工删除锁或改写状态绕过保护。

### 自动发布门禁

2026-11-10 用户明确授权每周任务自动发布，替代此前“仅同步不发布”的限制：上游、独立译表、冒险新增汉化和平台范围检查完成后，由独立测试任务验证本轮源码/新产物，通过后才能提交推送、上传版本专用文件并切换清单。普通客户端发布无需再次人工确认；涉及在线大厅协议/服务变更仍须提前通知并等待安排。

复用固定开发树和脚本，APK/Windows 完整安装器及便携包/资源包版本一致，Android versionCode 递增；不生成增量包。保存线上清单基线，上传后校验完整 SHA-256 和长度，确认源码推送成功且线上基线未变才切换入口，最后回读源站/CDN。失败保留旧入口，不能引用半成品。密钥不写入仓库或日志。其它项目改动不纳入本轮；暂时隔离必须经用户授权、完整备份并在构建后恢复。没有新内容不创建空版本。

默认独立测试范围为编译、自动化测试、静态检查，明确不覆盖界面交互、真实设备兼容性和所有玩法。

## 日常清理

```powershell
& ./deploy/cleanup-development-artifacts.ps1
# 阅读 dist/workspace-maintenance/cleanup-plan.json 后再执行：
& ./deploy/cleanup-development-artifacts.ps1 -Execute
```

规则在 `deploy/workspace-retention.json`。默认只在固定同步/开发工作树内清理超过 7 天的生成预览、测试目录，以及明确命名的下载验证副本/分片；不删除发布物、源码或构建缓存。校验日志在固定同步目录 `dist/build-logs/` 保存，每次一个 `run-*` 目录或 ZIP；清理脚本保留最近 8 次，只回收更老且超过 7 天的记录，不触碰正在写入的零散日志。避免复制完整工作区。

清理要求目标未跟踪且被 Git 忽略、目录无链接、工作树干净；存在同步运行租约或相关产物进程时拒绝执行。执行前再次比较整份预览的路径、类型、大小、文件数和时间，发生变化就重新生成预览。`-IncludeBuildCaches` 仅供明确需要释放编译缓存时手工使用，定时任务不得使用，否则会降低下次打包速度。
