# Forge 桌面对战皮肤制作入门

推荐示例「暮辉秘境」现已升级 v4，并内置于新版桌面客户端的「布局 → 对战界面」菜单。可用自定义图标、头像形状、按钮状态、生物居中和半透明浮窗；见 [v4 扩展制作说明](DesktopMatchSkin-v4.zh-CN.md)。本文的基础制作步骤适用于 v3/v4，局部 v3 代码是旧版基线，不要将新示例的 version 改为 3。需要旧客户端兼容时使用资料包 minimal 骨架。

这份说明写给想换背景、颜色、字体或调整对战画面的玩家。最省事的方法是复制现成皮肤，再少量修改，不需要学习 Java，也不需要重新编译游戏。

本文适用于支持 **match-ui 第 3 版接口的 Forge 汉化桌面程序**。它制作的是对局画面的皮肤，不是首页主题，也不能直接用于安卓版。旧安装包如果没有“布局 → 对战界面 → 导入对战皮肤包”，需要先换用支持此功能的程序。

## 先做一个只换背景的版本

1. 取得项目提供的“暮辉秘境”皮肤 ZIP，解压到一个自己的文件夹。源码中的原件在 `skins/dusk-sanctum/`。
2. 备份这个文件夹，不要直接修改唯一一份原件。
3. 用自己的 PNG 图片替换 `images/table.png`，保持文件名不变。
4. 用文本编辑器打开 `match-ui.json`，把开头的 `"id": "dusk-sanctum"` 改成 `"id": "my-first-skin"`。
5. 保存为 UTF-8。选中文件夹里面的文件和子文件夹，压缩成 ZIP。
6. 进入一局本地练习对战，打开“布局 → 对战界面 → 导入对战皮肤包”，选择这个 ZIP。

导入后即可看到效果。第一次先只换背景；确认能正常操作后，再换颜色或移动按钮。不要第一次就把所有位置都改掉。

## 一个皮肤包里面是什么

打开 ZIP 后应直接看到下面这些内容，而不是先看到一层 `my-first-skin` 文件夹：

```text
match-ui.json                 布局和颜色配置
images/
  table.png                   对战背景
fonts/
  NotoSansCJKsc-Regular.otf    中文字体
  OFL.txt                     随字体附带的许可
README.md                     给使用者看的说明
ASSETS.md                     图片和字体的来源说明
```

这里的图片和字体文件名来自示例，可以更换，但配置中的路径必须对应。请保留字体许可，使用自己制作或获准使用的图片。包内不要放 EXE、JAR、脚本、套牌、账户配置或私人文件。

卡牌图片、头像和游戏规则由 Forge 自己提供，不需要把全部卡图放进皮肤包。

## 哪些地方可以改

| 想改的效果 | 到哪里修改 |
| --- | --- |
| 桌面背景 | 替换 `images/table.png`，或修改 `scene.appearance.background` 的路径 |
| 中文字体 | 修改 `scene.appearance.font`，并把对应字体放入包内 |
| 普通文字颜色 | `scene.appearance.text` |
| 按钮颜色和字号 | `scene.appearance.styles.button` |
| 生命数字字号 | `scene.appearance.styles.life.fontSize` |
| 标签页颜色 | `scene.appearance.styles.tab` |
| 悬浮堆叠框外观 | `scene.appearance.styles.floating` |
| 手牌是否扇形 | `cards.hand` |
| 手牌展开角度 | `cards.fanDegrees`，允许 0～60 |
| 地牌在左、其他非生物永久物在右且不越中线 | 新版 v4 设置 `cards.battlefield` 为 `adaptive`，两边独立换行；需要 1.1.5 资料包对应或更新的客户端 |
| 头像、生命、按钮的位置 | `scene.widgets` 中对应项目的四个数字 |
| 战场、手牌、卡牌详情的位置 | `regions` 中相应区域的 `bounds` |

`scene.appearance.styles` 管颜色、图片、字号；`scene.styles` 管旧面板边框、底色和标题是否显示。这是两种不同设置，不要混在一起。

### 换背景

在 `scene` 里的 `appearance` 中找到：

```json
"background": "images/table.png"
```

如果换成 `my-table.jpg`，对应改为 `"images/my-table.jpg"`。路径用 `/`，不是 Windows 的 `\`。不要填写 `C:` 盘路径或网址。

建议从 1920×1080 左右的横向背景开始，这是制作建议，不是硬性尺寸要求。图片会随窗口拉伸；不要把必须准确对齐的按钮文字画在背景上，真正的按钮仍应由程序显示。背景尽量不要太花，以免盖过卡牌和提示。

### 换颜色和字体大小

例如，找到 `appearance.styles` 里的 `button`，把这个小对象改成下面这样。**这是局部替换示例，不是完整配置文件。**

```json
"button": {
  "fill": "#243B53",
  "border": "#9FB3C8",
  "highlight": "#3E8E9E",
  "radius": 10,
  "padding": 3,
  "fontSize": 15
}
```

- `fill`：底色。
- `border`：边线颜色。
- `highlight`：控件在支持的选中或激活状态下使用的强调色，不是统一的鼠标悬停色。
- `radius`：圆角参数，0～80。
- `padding`：内部留白，0～32。
- `fontSize`：字号，8～64。

颜色用 `#RRGGBB`；也可加最后两位透明度，例如 `#111B23B0`。`FF` 完全不透明，`00` 完全透明。

建议保留示例中文字体。换成只有英文字形的字体，可能再次出现方框或缺字。字号调大后也要检查按钮是否装得下。

### 调整位置

例如 `"FIELD_0.LIFE": [0.11, 0.53, 0.064, 0.065]` 的四个数字依次是：

| 数字 | 含义 |
| --- | --- |
| 第 1 个 | 离左边多远，0.11 表示画面宽度的 11% |
| 第 2 个 | 离上边多远，0.53 表示画面高度的 53% |
| 第 3 个 | 占多宽，0.064 表示宽度的 6.4% |
| 第 4 个 | 占多高，0.065 表示高度的 6.5% |

这里的“画面”是对战内容区，不包括操作系统标题栏。向右移就增加第一个数，向下移就增加第二个数。先按 0.005 或 0.01 小幅调整。

宽和高必须大于 0；左边位置加宽度不能超过 1，上边位置加高度不能超过 1。固定控件和固定区域不能互相重叠，隐藏时也要预留位置。放大一个控件之前，先给它腾地方。

普通双人对战中，`FIELD_0` 通常是自己的视角，`FIELD_1` 是另一位玩家；观战时不要把 0 理解成必然属于自己。不要随意改这些名字。

## 新手不要删除的内容

可以改颜色和位置，但先保留示例原有的功能入口：

- 自己的真实手牌区域 `hands`。对手的 `HAND_BACKS` 只是牌背数量示意，不能代替它。
- 双方的战场、头像、生命、玩家状态、法术力与区域入口。
- 当前阶段条 `PHASES_ACTIVE`。
- 提示 `PROMPT_MESSAGE`、确认 `PROMPT_OK`、取消 `PROMPT_CANCEL`。
- “对战操作”入口 `ACTIONS_MENU`。
- 堆叠、卡牌预览和详情、日志等查看方式。

示例的法术力条在没有法术力时隐藏，堆叠在没有咒语或异能时隐藏，这是正常效果。不要为了让画面更干净，把确认、取消、生命或阶段条藏起来。

暮辉秘境是双人布局。多人对战或同时显示多副受控手牌时，程序会回退到能容纳全部信息的布局，这不是皮肤丢失。

## 导入后修改为什么没生效

导入会把 ZIP 安装成独立副本。之后修改你桌面上原来的文件夹，不会自动修改游戏里的副本。

有两种做法：

1. **简单做法**：改原稿，重新压缩并导入。每次会新增一个副本，再从“已保存的对战皮肤”选择需要的版本。
2. **熟练后使用**：修改已安装副本，再点“重新加载界面配置”。请先备份，别改错其他副本。

Windows 默认安装位置通常为：

```text
%APPDATA%\Forge\preferences\desktop-match-skins\
```

可把这行粘贴到资源管理器地址栏。里面类似 `my-first-skin-a1b2c3d4` 的文件夹就是独立副本。如果设置过自定义用户目录，实际位置是该用户目录下的 `preferences/desktop-match-skins/`，不一定在默认位置。

“使用皮肤布局”是读取 Forge 当前传统主题目录里的配置；它与导入 ZIP 后选择“已保存的对战皮肤”不是同一个入口。入门阶段建议只使用 ZIP 导入方式。

### 保存、切换和删除

导入 ZIP 会永久保存一份独立副本，不只是临时预览。即使移动原始 ZIP、退出程序或重新启动，仍可从“布局 → 对战界面 → 已保存的对战皮肤”选择；列表会标记当前使用的皮肤，每次打开菜单刷新，不需要重新开一局。名称末尾的随机后缀用来区分多次导入的不同副本，不会覆盖旧版本。

删除不需要的版本：选择“布局 → 对战界面 → 删除已保存的皮肤…”，选中一个副本，再确认。默认选“取消”；若删除的是当前正在使用的皮肤，会先恢复经典布局，不结束对局。只有确认删除的副本目录会被移除，原始 ZIP、其他皮肤、套牌与存档不受影响；内置暮辉秘境和经典布局不在删除列表中。

删除是永久删除，释放其安装文件占用的磁盘空间，不移到隐藏备份目录。需要恢复时重新导入原始 ZIP。请先把自己直接修改过的安装副本备份到原稿或重新打包；原始 ZIP 不会自动包含这些修改。若系统阻止删除，查看错误提示，剩余文件通常仍保留在该副本目录，排除占用后可再次删除。

## 打包前检查

1. `match-ui.json` 真正以 `.json` 结尾，不是 `.json.txt`。
2. 使用英文双引号、英文逗号，最后一项后面不多写逗号；不要加入注释。
3. `version` 保持数字 `3`。`id` 用小写英文开头，只用小写英文、数字、连字符，最长 64 字符，例如 `blue-table-v2`。
4. ZIP 最外层直接有 `match-ui.json`；配置引用的图片和字体全部在包内。
5. 使用 ZIP，不是 RAR 或 7z；不要设置压缩密码。
6. 单个文件不超过 24 MiB，解压总大小不超过 64 MiB，ZIP 内文件和目录条目总数不超过 256。不要放 PSD、SVG、视频和无关原稿。

导入失败时先读错误提示。通常是 JSON 标点、路径、重叠或体积问题，不需要重新安装整个游戏。

## 发布给别人之前试一次

在本地练习局中检查下面这些操作，不要在重要联机局里首次测试：

- 起手牌能看清，点击和拖到战场能正常出牌。
- 施放咒语时提示、确认、取消都能用。
- 有法术力时能看到法术力条，支付后能正确更新。
- 有堆叠时能查看内容和目标，清空后能隐藏。
- 坟墓场、放逐区、卡牌详情和对战操作能打开。
- 缩小窗口和最大化后，控件没有遮挡，文字没被截断。
- 切回“经典布局”还能继续操作。

用多个窗口尺寸和实际使用的系统缩放比例测试。不要只凭一张好看的截图就写“全部适配”。

## 常见问题

| 现象 | 先检查 |
| --- | --- |
| 找不到导入菜单 | 是否为支持新接口的桌面程序，且已进入对局 |
| 修改后没变化 | 改的是原稿还是游戏安装的副本，是否重新导入或重新加载 |
| 出现“已恢复经典布局” | JSON 格式、缺少控件、重叠、文件路径；保留错误原文排查 |
| 变成常规面板布局 | 当前人数或可见手牌数量超出示例皮肤容量，内部安全回退仍然保留，但不再单独出现在菜单 |
| 背景能显示，中文成方框 | 字体是否包含中文，是否保留了正确的字体路径 |
| 字变大后按钮显示不全 | 同时增加按钮可用空间，避免只改字号 |
| 没看到堆叠或法术力 | 先确认堆叠是否为空、该玩家法术力池是否为零 |
| 拖动堆叠后重开位置还原 | 目前不跨重启保存悬浮位置，应修改配置里的默认位置 |

更复杂的调整可把 [AI 皮肤制作规范](DesktopMatchSkin-AI-Spec.zh-CN.md) 和完整原稿一起交给 AI。明确告诉它：只修改数据皮肤，保留所有游戏操作，不修改游戏规则。
