Desktop match layouts can also be customized with a skin's `match-ui.json`.
See [PC 对战界面扩展接口](DesktopMatchUI.zh-CN.md) for the configuration format, example and Java extension points.

The desktop v4 authoring extension is documented in [v4 皮肤制作说明](DesktopMatchSkin-v4.zh-CN.md). Existing v1-v3 skins retain their behavior.

Dusk Sanctum is the built-in desktop v4 example under Layout → Match UI. Its editable source in `skins/dusk-sanctum/` is shared by the desktop JAR and the independent authoring kit. The old Arena and Tabletop preview menu entries are retired; multiplayer capacity fallback remains internal.

cn1002 adds the v5 Dusk Observatory example in `skins/dusk-observatory/`, responsive and multiplayer scenes, personal preferences and a geometry editor. See [v5 皮肤制作说明](DesktopMatchSkin-v5.zh-CN.md) and the [standalone authoring kit 2.0.1](https://update.mtg-forge-kaorou.vip/forge/tools/2.0.15-cn1002/Forge-Skin-Authoring-Kit-2.0.1.zip); capability revision is `2026-10-02.1`.
